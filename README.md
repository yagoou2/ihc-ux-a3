# LogiCode: Gamificação no Ensino de Lógica de Programação

## 🚀 Sobre o Projeto
O **LogiCode** é uma plataforma educacional desenvolvida como solução para mitigar as altas taxas de evasão escolar nos cursos de Tecnologia da Informação (TI). Atuando na lacuna entre a teoria abstrata e a prática, utilizamos a **gamificação** e o **microlearning** para tornar o aprendizado de lógica uma jornada envolvente, intuitiva e acessível.

O projeto foi concebido no âmbito da disciplina de *Interação Humano-Computador (IHC) e UX* da Faculdade UNA de Contagem (2026), com o foco de transformar o erro de código em uma oportunidade de aprendizado através de *feedback* contextual.

---

## 💡 O Problema
Estudos indicam que aproximadamente **75% dos alunos de TI no Brasil abandonam os cursos** antes da formatura. O fenômeno do "isolamento conceitual" — onde estudantes se perdem em sintaxes complexas sem obter *feedback* imediato — é a principal barreira para a retenção desses talentos.

---

## 🛠 A Solução: LogiCode
Nossa abordagem é centrada no usuário, priorizando a eficácia pedagógica sobre a complexidade visual:
* **Interface via CLI (Terminal):** Foco total no fluxo lógico. Eliminamos distrações visuais para que o aluno se concentre no que realmente importa: a estrutura do código.
* **Aprendizagem Gamificada:** Implementação de sistemas de XP, *streaks* (assiduidade) e desafios progressivos.
* **Offline-First:** Arquitetura robusta com SQLite, permitindo que o aluno pratique em qualquer ambiente, sem dependência de internet.
* **Feedback Inteligente:** Mensagens de erro que indicam exatamente o ponto de ruptura, transformando a frustração em guia para o próximo desafio.
